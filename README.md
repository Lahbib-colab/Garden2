# 🌿 LawnNotifier

PWA de planification de tonte — iOS 27 Design · Météo · IA

## Déploiement GitHub Pages

1. Dézippez cette archive dans votre dossier de projet local.
2. Envoyez les fichiers vers GitHub :

```bash
git add .
git commit -m "Correction chemins relatifs v9"
git push
```

3. Vérifiez dans **Settings → Pages** que la source est positionnée sur `main / (root)`.
